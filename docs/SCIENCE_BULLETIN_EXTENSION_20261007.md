
# Science Bulletin extension (7 October 2026)

This directory adds the fully retained material-substitution, additional-service, signed-inventory, and heat-loss assessments used in the Science Bulletin submission. The extension preserves failed, unsupported-domain, and numerically sensitive outcomes alongside feasible results.

Key verified results are: 42 of 208 cross-material reduced-count tests remain feasible on both 2,048- and 4,096-cell grids; the qualified-energy increase for those 42 tests is 8.28–20.70%; all 52 same-material boundary controls change feasibility between grids; all 24 additional energy-controlled service counts are reproduced on both grids; and 12 severe-loss trajectories show decreasing installed qualified energy as module count increases.

This extension is distributed through https://github.com/ChunleiWu-tech/TES-Optimization together with its code, inputs, processed results, and verification records.
